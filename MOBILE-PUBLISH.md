# Быстрая публикация с телефона

В архиве есть готовая одна страница: `mobile-upload/index.html`.

1. Распакуйте архив на телефоне.
2. В GitHub откройте репозиторий `Arame195/mezhdu-nami` и выберите **Add file → Upload files**.
3. Загрузите `mobile-upload/index.html` в корень репозитория. Если GitHub спросит, подтвердите замену имеющегося `index.html`.
4. Нажмите **Commit changes**.
5. В **Settings → Pages** выберите публикацию из ветки `main`, папка `/ (root)`, и сохраните.
6. Дождитесь публикации. Адрес сайта будет `https://arame195.github.io/mezhdu-nami/`.

Одностраничная версия сохраняет все сцены, стили и логику внутри одного файла. Three.js, GSAP, Lenis и шрифты загружаются из CDN, поэтому для них нужен интернет. Поле ответа хранит черновик только на устройстве и ничего не отправляет.

Полный исходный проект находится в корне архива; он включает отдельные `index.html`, `styles.css`, `app.js`, workflow GitHub Pages и собранную папку `dist`.
