# «Между нами»

Одностраничная интерактивная история на HTML, CSS и JavaScript. В проекте семь управляемых сцен; Three.js рисует звёздное пространство и созвездие, GSAP отвечает за переходы, а Lenis и ScrollTrigger подключаются только на экранах, которые действительно прокручиваются.

## Запуск и сборка

Зависимости устанавливать не нужно: GSAP, Three.js и Lenis подключены по закреплённым версиям CDN. Для production-сборки нужен Node.js 20 или новее:

```sh
node scripts/build.mjs
```

Готовая статическая версия появится в `dist/`. Для локального просмотра после сборки:

```sh
node scripts/preview.mjs
```

Откройте `http://127.0.0.1:4173`.

## Тексты и воспоминания

Все изменяемые тексты находятся в объекте `CONFIG` в начале `app.js`: `memories`, `letter`, `freedom`, `finalMessage`, `prompts` и тексты заголовков. Воспоминания сейчас — нейтральные примеры-заполнители; добавьте настоящие формулировки перед отправкой проекта.

## Черновик ответа

Финальное поле сохраняет черновик в `localStorage` этого браузера и на этом устройстве. Серверной отправки нет. Кнопка копирования использует системный буфер обмена; сайт не утверждает, что доставил сообщение.

## Публикация

Проект подготовлен к GitHub Pages через workflow `.github/workflows/pages.yml`. Для публикации репозиторий должен быть на GitHub, а в **Settings → Pages → Build and deployment → Source** нужно выбрать **GitHub Actions**. После отправки ветки `main` workflow соберёт `dist/` и развернёт сайт. GitHub Pages публикует общедоступную страницу; не добавляйте в неё личные фотографии или сведения, которые не хотите показывать публично.

Без GitHub-подключения в этой среде исходники и workflow готовы, но создать репозиторий, отправить коммит и получить адрес Pages не получится.
