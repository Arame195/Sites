# «Между нами»

Одностраничная интерактивная история из шести сцен. Воспоминания открываются в космической карте, затем можно собрать созвездие и направить луч к маяку с помощью четырёх поворотных зеркал. Экран «Четыре опоры» сохранён, а финальная сцена даёт место для готового ответа или собственного текста.

Three.js рисует звёздное пространство и созвездие, GSAP отвечает за переходы и игровые реакции. Lenis и ScrollTrigger подключаются только для экранов, где действительно нужна прокрутка.

## Запуск и сборка

Самый простой запуск: откройте `index.html` двойным щелчком. Файлы `styles.css` и `app.js` лежат рядом, установка зависимостей не требуется. Сцены, кнопки и игры работают и при прямом открытии файла; Three.js, GSAP и Lenis подключаются как улучшения, поэтому при отсутствии сети сайт сохранит базовую интерактивность и плавные CSS-переходы.

Для production-сборки нужен Node.js 20 или новее:

```sh
node scripts/build.mjs
```

Готовая статическая версия появится в `dist/`. Если нужен локальный адрес `http://127.0.0.1:4173`, запустите:

```sh
node scripts/preview.mjs
```

Откройте `http://127.0.0.1:4173`.

## Тексты и воспоминания

Изменяемые тексты находятся в объекте `CONFIG` в начале `app.js`: `memories`, `memoryAside`, `constellationQuote`, `mirrorStart`, `mirrorSolution`, `promiseItems`, `conversationHeading`, `conversationLead`, `conversationBetween` и `conversationOptions`. Воспоминания — нейтральные примеры-заполнители; замените их настоящими формулировками перед публикацией.

## Черновик ответа

Финальное поле сохраняет черновик в `localStorage` этого браузера и на этом устройстве. Серверной отправки нет. Кнопка копирования использует системный буфер обмена; сайт не утверждает, что доставил сообщение.

## Публикация

Проект подготовлен к GitHub Pages через workflow `.github/workflows/pages.yml`. Для публикации репозиторий должен быть на GitHub, а в **Settings → Pages → Build and deployment → Source** нужно выбрать **GitHub Actions**. После отправки ветки `main` workflow соберёт `dist/` и развернёт сайт. GitHub Pages публикует общедоступную страницу; не добавляйте в неё личные фотографии или сведения, которые не хотите показывать публично.

Если репозиторий использует GitHub Actions как источник GitHub Pages, workflow соберёт сайт при отправке ветки `main`. Для публикации из корня ветки используйте **GitHub Pages → Deploy from a branch → `main` → `/(root)`**; корневые `index.html`, `styles.css` и `app.js` работают без сборки.
